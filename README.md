# Prumo

Gestor de tempo pessoal: quadro kanban, agenda, matriz de Eisenhower, pomodoro, projetos e metas.

- Funciona 100% no navegador, sem conta e sem servidor.
- Os dados ficam só no aparelho de cada pessoa (armazenamento local). Use Ajustes › Seus dados para baixar e restaurar backup.
- Pode ser instalado no celular (menu do navegador › Adicionar à tela inicial) e funciona offline.
